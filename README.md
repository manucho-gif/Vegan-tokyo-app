# Vegan Tokyo App

iPhone-optimierte PWA für vegane Orte in Tokio.

## Funktionen
- interaktive Karte
- Brunch, Lunch, Dinner, Café, Bäckerei und Einkauf
- Suche und Favoriten
- eigener Standort
- Apple Maps und Google Maps
- eigene Orte direkt auf dem iPhone hinzufügen
- als App über «Zum Home-Bildschirm» installierbar

## Veröffentlichung
1. Alle Dateien in den `main`-Branch hochladen.
2. Repository → Settings → Pages.
3. Source auf **GitHub Actions** setzen.
4. Workflow ausführen lassen.
5. Pages-Link in Safari öffnen.
6. Teilen → **Zum Home-Bildschirm**.

Eigene Orte und Favoriten werden lokal im Browser gespeichert.
